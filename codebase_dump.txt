===== FILE: README.md =====
# Viet Keyboard (MVP)

Scaffold bàn phím Android (IME) tập trung vào 3 tính năng được yêu cầu:

- **Macro/Gõ tắt**: thay thế shortcut khi gõ dấu phân cách (`space`, `.`, `,`, ...).
- **Bỏ dấu tự do**: nút `Bỏ dấu` để bỏ dấu vùng chọn, từ đang composing, hoặc từ gần con trỏ.
- **Gợi ý từ cơ bản**: suggestion bar theo prefix (dictionary MVP).

> Đây là MVP để triển khai nhanh, **không phải bản copy đầy đủ GBoard**. 

## Cấu trúc

```text
viet-keyboard/
  app/src/main/java/com/vnchflex/vietkeyboard/
    ime/        # InputMethodService, wiring phím
    engine/     # Telex MVP + DiacriticUtils (bỏ dấu tự do)
    macro/      # Macro model/store/engine
    suggestion/ # Gợi ý từ cơ bản
    settings/   # Màn hình mở cài đặt IME
  app/src/main/res/
    layout/keyboard_view.xml
    xml/method.xml
```

## Tính năng đã có

### 1. Macro / Gõ tắt
- `MacroEngine` kiểm tra token trước con trỏ khi gặp trigger.
- `MacroStore` lưu macro bằng `SharedPreferences` (JSON).
- Macro mẫu: `addr`, `email`, `shrug`.
- Biến MVP: `{date}`, `{time}`.

Ví dụ: gõ `addr` + `Space` => thay bằng địa chỉ + khoảng trắng.

### 2. Bỏ dấu tự do (kiểu vnchKey)
- `DiacriticUtils.strip()` chuẩn hóa NFD, bỏ `\p{Mn}`, đổi `đ/Đ -> d/D`.
- Nút `Bỏ dấu` trên bàn phím:
  - Nếu có selection: bỏ dấu selection.
  - Nếu đang composing: bỏ dấu buffer composing.
  - Nếu không: bỏ dấu từ ngay trước con trỏ.

### 3. Gợi ý từ cơ bản
- `SuggestionEngine` gợi ý prefix từ dictionary nhỏ + từ người dùng đã chọn.
- Chạm suggestion để thay prefix hiện tại.

### 4. Engine tiếng Việt (MVP)
- `VietnameseEngine` có Telex cơ bản cho tone (`s/f/r/x/j`, `z` bỏ dấu) và shape (`a/e/o/w/d`) ở mức đơn giản.
- Cần nâng cấp thành parser âm tiết đầy đủ cho độ chính xác production.

## Chạy dự án

Yêu cầu: Android Studio / Android SDK + JDK 17.

```bash
# từ thư mục viet-keyboard
gradle wrapper   # nếu chưa có wrapper jar
./gradlew assembleDebug
```

Sau khi cài APK:
1. Mở app Viet Keyboard.
2. Bấm **Mở cài đặt bàn phím** và bật Viet Keyboard.
3. Chọn Viet Keyboard khi nhập liệu.

## Hướng cải tiến tiếp theo

- **Engine VN đầy đủ**: parser âm tiết, đặt dấu đúng quy tắc + chế độ đặt dấu tự do, Telex/VNI đầy đủ.
- **Macro nâng cao**: UI quản lý macro, import/export, `{clipboard}`, `{cursor}`, undo macro, đồng bộ.
- **Gợi ý chất lượng cao**: n-gram/on-device LM, autocorrect, cá nhân hóa, tiếng Việt + Anh.
- **UX kiểu GBoard**: long-press popup, gesture vuốt, emoji/clipboard panel, theme, one-handed.
- **Tương thích InputConnection**: test Chrome/WebView/rich editor, batch edit, selection edge cases.
- **Kiểm thử**: unit test cho engine/macro/diacritics, instrumented test IME.

- Macro và dữ liệu gõ nên giữ local-by-default, rõ ràng về quyền riêng tư.

package com.vnchflex.vietkeyboard.engine

import java.text.Normalizer

object DiacriticUtils {
    private val COMBINING_MARKS = Regex("\\p{Mn}+")

    /** Removes Vietnamese diacritics, including đ/Đ. */
    fun strip(input: String): String {
        if (input.isEmpty()) return input
        val normalized = Normalizer.normalize(input, Normalizer.Form.NFD)
        return COMBINING_MARKS.replace(normalized, "")
            .replace('đ', 'd')
            .replace('Đ', 'D')
    }

    /**
     * "Bỏ dấu tự do" style toggle: if text contains diacritics, strip them;
     * otherwise return original. Caller can extend with re-apply logic.
     */
    fun toggleStrip(input: String): String {
        val stripped = strip(input)
        return if (stripped == input) input else stripped
    }
}

package com.vnchflex.vietkeyboard.engine

import android.view.inputmethod.InputConnection

/**
 * Engine Tiếng Việt Telex Bỏ dấu tự do theo phong cách vnchKey:
 * - Thuần Telex (loại bỏ VNI và loại bỏ SenFlex dấu trước âm phức tạp).
 * - Bỏ dấu tự do chuẩn vnchKey: người dùng có thể gõ dấu thanh (`s, f, r, x, j, z`) hoặc dấu mũ/móc/đ (`aa, ee, oo, aw, ow, uw, dd`)
 *   ngay sau nguyên âm hoặc ở cuối chữ sau phụ âm cuối (ví dụ: `vieetj` hoặc `vietej` -> `việt`, `nhana` -> `nhân`,
 *   `truwongr` hoặc `truongwr` -> `trưởng`, `dduowcj` hoặc `duocwdj` -> `được`).
 * - Hỗ trợ đầy đủ từ phương ngữ Nam Bộ & phụ âm mở rộng (`dz-`, `z-`, `f-`, `j-`, `w-`) giống vnchKey:
 *   + `dziaf` -> `dzìa`, `dzachs` -> `dzách`, `dzoo` -> `dzô`, `dzoj` -> `dzọ`, `dzui` -> `dzui`, `dzaayj` -> `dzậy`, `dzotj` -> `dzọt`
 *   + `zaayj` -> `zậy`, `zui` -> `zui`, `fairs` -> `fải`, `was` -> `wá`, `waayj` -> `wậy`, `jups` -> `júp`
 *   + Giữ nguyên các từ tiếng Anh có phụ âm mở rộng (`zero`, `zone`, `zip`, `zest`, `just`, `free`, `fee`, `water`, `web`)
 * - Đặt dấu đúng vị trí nguyên âm theo chuẩn chính tả mới (`òa, òe, úy`) hoặc cũ (`oà, oè, uý`).
 * - Lặp phím dấu / phím mũ-móc để hoàn nguyên (escape) khi gõ tiếng Anh (`canhf + f -> canhf`, `aaa -> aa`, `ww -> w`, `ddd -> dd`).
 * - Nút `Bỏ dấu` (`removeDiacritics`) hoặc phím `z` để xóa dấu tự do.
 */
class VietnameseEngine {
    enum class Tone(val index: Int) {
        NONE(0),
        ACUTE(1), // Sắc (s)
        GRAVE(2), // Huyền (f)
        HOOK(3),  // Hỏi (r)
        TILDE(4), // Ngã (x)
        DOT(5)    // Nặng (j)
    }

    var freeTonePlacement: Boolean = true
    var modernOrthography: Boolean = true
    var quickTelex: Boolean = false
    var relaxedCoda: Boolean = false
    /** Cho phép gõ từ phương ngữ Nam Bộ (`dzìa`, `dzách`, `dzô`...) và phụ âm mở rộng (`f, j, w, z`) chuẩn vnchKey */
    var southernDialectAndGenZ: Boolean = true

    private val rawChars = mutableListOf<Char>()
    private var renderedOutput: String = ""

    val composingText: String get() = renderedOutput
    val isComposing: Boolean get() = rawChars.isNotEmpty()

    fun onChar(input: Char, ic: InputConnection): Boolean {
        if (input.isLetter()) {
            rawChars.add(input)
            renderedOutput = transformTelex(rawChars)
            ic.setComposingText(renderedOutput, 1)
            return true
        }
        commit(ic)
        return false
    }

    fun onBackspace(ic: InputConnection): Boolean {
        if (rawChars.isEmpty()) return false
        if (renderedOutput.isNotEmpty()) {
            val updated = renderedOutput.dropLast(1)
            if (updated.isEmpty()) {
                rawChars.clear()
                renderedOutput = ""
                ic.finishComposingText()
            } else {
                renderedOutput = updated
                rawChars.clear()
                rawChars.addAll(rawKeysFor(updated).toList())
                ic.setComposingText(renderedOutput, 1)
            }
            return true
        }
        rawChars.removeAt(rawChars.lastIndex)
        renderedOutput = if (rawChars.isEmpty()) "" else transformTelex(rawChars)
        if (renderedOutput.isEmpty()) ic.finishComposingText() else ic.setComposingText(renderedOutput, 1)
        return true
    }

    fun commit(ic: InputConnection) {
        if (renderedOutput.isEmpty() && rawChars.isEmpty()) return
        ic.commitText(renderedOutput, 1)
        rawChars.clear()
        renderedOutput = ""
    }

    fun reset(ic: InputConnection? = null) {
        rawChars.clear()
        renderedOutput = ""
        ic?.finishComposingText()
    }

    /** Bỏ dấu tự do (kiểu vnchKey): xóa dấu trên từ đang gõ, vùng đang chọn, hoặc từ ngay trước con trỏ. */
    fun removeDiacritics(ic: InputConnection) {
        if (rawChars.isNotEmpty()) {
            val stripped = DiacriticUtils.strip(renderedOutput)
            rawChars.clear()
            rawChars.addAll(stripped.toList())
            renderedOutput = stripped
            ic.setComposingText(renderedOutput, 1)
            return
        }
        val selected = ic.getSelectedText(0)?.toString()
        if (!selected.isNullOrEmpty()) {
            ic.commitText(DiacriticUtils.strip(selected), 1)
            return
        }
        val before = ic.getTextBeforeCursor(64, 0)?.toString().orEmpty()
        val word = before.takeLastWhile { !it.isWhitespace() }
        if (word.isEmpty()) return
        ic.beginBatchEdit()
        try {
            ic.deleteSurroundingText(word.length, 0)
            ic.commitText(DiacriticUtils.strip(word), 1)
        } finally {
            ic.endBatchEdit()
        }
    }

    // ==================== TELEX BỎ DẤU TỰ DO & PHƯƠNG NGỮ NAM BỘ (PHONG CÁCH VNCHKEY) ====================
    fun transformTelex(chars: List<Char>): String {
        if (chars.isEmpty()) return ""
        val lowerRaw = chars.map { it.lowercaseChar() }.joinToString("")

        // Kiểm tra phụ âm đầu không chuẩn tiếng Việt (dz-, f-, j-, z-, w-) theo quy tắc vnchKey
        val firstLower = lowerRaw.first()
        val isDzOnset = lowerRaw.startsWith("dz")
        if (!southernDialectAndGenZ && (isDzOnset || firstLower == 'f' || firstLower == 'j' || firstLower == 'z')) {
            return chars.joinToString("")
        }
        if (southernDialectAndGenZ && !isDzOnset && (firstLower == 'f' || firstLower == 'j' || firstLower == 'z')) {
            // Bảo vệ các từ tiếng Anh thông dụng bắt đầu bằng f/j/z (free, fee, zero, zone, zip, zest, just...)
            if (lowerRaw in ENGLISH_FJZ_PROTECTED_WORDS ||
                (firstLower == 'f' && lowerRaw.startsWith("fr")) ||
                ((firstLower == 'z' || firstLower == 'j') && lowerRaw.endsWith("st"))
            ) {
                return chars.joinToString("")
            }
        }

        // Xử lý từ bắt đầu bằng 'w' trong chế độ Nam Bộ / Gen-Z (vd: was -> wá, waayj -> wậy, wans -> wán)
        if (southernDialectAndGenZ && firstLower == 'w' && chars.size >= 3) {
            val c1 = chars[1].lowercaseChar()
            if ((c1 == 'a' || c1 == 'e' || c1 == 'y') && lowerRaw !in ENGLISH_W_PROTECTED_WORDS) {
                val zChars = chars.toMutableList().apply { this[0] = if (chars[0].isUpperCase()) 'Z' else 'z' }
                val zTransformed = transformTelexCore(zChars, isDzOnset = false)
                if (zTransformed.lowercase() != zChars.joinToString("").lowercase()) {
                    return chars[0] + zTransformed.drop(1)
                }
            }
        }

        return transformTelexCore(chars, isDzOnset = isDzOnset)
    }

    private fun transformTelexCore(chars: List<Char>, isDzOnset: Boolean): String {
        val result = mutableListOf<Char>()
        var tone = Tone.NONE
        var toneEscapeActive = false
        var hornCancelled = false
        var circumflexCancelledKey: Char? = null
        var strokeDCancelled = false

        var i = 0
        // Nếu từ bắt đầu bằng phụ âm kép Nam Bộ "dz" (vd: dzìa, dzách, dzô, dzậy, dzọt, dzui),
        // giữ nguyên cụm phụ âm đầu "dz" không biến đổi thành "đ" và nhận diện nguyên âm + dấu thanh bình thường.
        if (isDzOnset && chars.size >= 2) {
            result.add(chars[0])
            result.add(chars[1])
            i = 2
        }

        while (i < chars.size) {
            val ch = chars[i]
            val lower = ch.lowercaseChar()

            // 1. Check dd -> đ và ddd -> dd (escape) khi không phải onset Nam Bộ "dz"
            if (!isDzOnset && lower == 'd' && !result.any { isVietnameseVowel(it) }) {
                if (i + 2 < chars.size &&
                    chars[i + 1].lowercaseChar() == 'd' &&
                    chars[i + 2].lowercaseChar() == 'd'
                ) {
                    result.add(ch)
                    result.add(chars[i + 1])
                    strokeDCancelled = true
                    toneEscapeActive = true
                    i += 3
                    continue
                }
                if (i + 1 < chars.size && chars[i + 1].lowercaseChar() == 'd') {
                    result.add(if (ch.isUpperCase()) 'Đ' else 'đ')
                    i += 2
                    continue
                }
            }

            // 2. Quick Telex phụ âm đầu (cc -> ch, gg -> gi, qq -> qu)
            if (quickTelex && result.isEmpty() && i + 1 < chars.size) {
                val nextLower = chars[i + 1].lowercaseChar()
                if (lower == 'c' && nextLower == 'c') {
                    result.addAll((if (ch.isUpperCase()) "Ch" else "ch").toList())
                    i += 2
                    continue
                }
                if (lower == 'g' && nextLower == 'g') {
                    result.addAll((if (ch.isUpperCase()) "Gi" else "gi").toList())
                    i += 2
                    continue
                }
                if (lower == 'q' && nextLower == 'q') {
                    result.addAll((if (ch.isUpperCase()) "Qu" else "qu").toList())
                    i += 2
                    continue
                }
            }

            // 3. Lặp 3 nguyên âm để hoàn nguyên (aaa -> aa, eee -> ee, ooo -> oo)
            if (!toneEscapeActive && (lower == 'a' || lower == 'e' || lower == 'o') &&
                i + 2 < chars.size &&
                chars[i + 1].lowercaseChar() == lower &&
                chars[i + 2].lowercaseChar() == lower
            ) {
                result.add(ch)
                result.add(chars[i + 1])
                tone = Tone.NONE
                circumflexCancelledKey = lower
                i += 3
                continue
            }

            // 4. Hai nguyên âm liền nhau tạo dấu mũ (aa -> â, ee -> ê, oo -> ô)
            if (!toneEscapeActive && (lower == 'a' || lower == 'e' || lower == 'o') &&
                i + 1 < chars.size &&
                chars[i + 1].lowercaseChar() == lower &&
                circumflexCancelledKey != lower
            ) {
                val hasPriorCircumflex = result.any { "âêôă".contains(it.lowercaseChar()) }
                if (!hasPriorCircumflex) {
                    val circumflex = when (lower) {
                        'a' -> if (ch.isUpperCase()) 'Â' else 'â'
                        'e' -> if (ch.isUpperCase()) 'Ê' else 'ê'
                        else -> if (ch.isUpperCase()) 'Ô' else 'ô'
                    }
                    result.add(circumflex)
                    i += 2
                    continue
                }
            }

            // 5. Bỏ dấu mũ & gạch ngang chữ đ tự do ở cuối từ (nhana -> nhân, vietej -> việt, trongo -> trông, dodongf -> đồng)
            // Lưu ý: Không biến đổi 'd' của phụ âm đầu Nam Bộ "dz" thành "đz"
            if (freeTonePlacement && !toneEscapeActive && result.isNotEmpty()) {
                if (!isDzOnset && lower == 'd' && result.any { isVietnameseVowel(it) }) {
                    val firstLower = result.first().lowercaseChar()
                    if (firstLower == 'd' && !strokeDCancelled) {
                        result[0] = if (result[0].isUpperCase()) 'Đ' else 'đ'
                        i += 1
                        continue
                    } else if (firstLower == 'đ') {
                        result[0] = if (result[0].isUpperCase()) 'D' else 'd'
                        strokeDCancelled = true
                        result.add(ch)
                        i += 1
                        continue
                    }
                }

                if ((lower == 'a' || lower == 'e' || lower == 'o') && circumflexCancelledKey != lower) {
                    val targetIdx = result.indexOfLast {
                        val c = it.lowercaseChar()
                        c == lower || (lower == 'o' && c == 'ơ') || (lower == 'a' && c == 'ă')
                    }
                    if (targetIdx >= 0 && (targetIdx < result.lastIndex || result[targetIdx].lowercaseChar() != lower)) {
                        val isUpper = result[targetIdx].isUpperCase()
                        if (lower == 'o' && targetIdx >= 1 && result[targetIdx - 1].lowercaseChar() == 'ư') {
                            result[targetIdx - 1] = if (result[targetIdx - 1].isUpperCase()) 'U' else 'u'
                        }
                        result[targetIdx] = when (lower) {
                            'a' -> if (isUpper) 'Â' else 'â'
                            'e' -> if (isUpper) 'Ê' else 'ê'
                            else -> if (isUpper) 'Ô' else 'ô'
                        }
                        i += 1
                        continue
                    }
                }
            }

            // 6. Phím w (aw -> ă, ow -> ơ, uw -> ư, uow -> ươ, ww -> w)
            if (lower == 'w') {
                if (hornCancelled) {
                    result.add(ch)
                    i += 1
                    continue
                }
                if (i + 1 < chars.size && chars[i + 1].lowercaseChar() == 'w') {
                    result.add(ch)
                    hornCancelled = true
                    i += 2
                    continue
                }
                var transformed = false
                val searchIndices = if (freeTonePlacement) result.indices.reversed() else listOfNotNull(result.indices.lastOrNull())
                for (idx in searchIndices) {
                    val vLower = result[idx].lowercaseChar()
                    val vUpper = result[idx].isUpperCase()
                    if (vLower == 'ă' || vLower == 'ư' || vLower == 'ơ') {
                        break
                    } else if (vLower == 'a' || vLower == 'â') {
                        if (idx >= 1 && result[idx - 1].lowercaseChar() == 'u') {
                            val isAfterQ = idx >= 2 && result[idx - 2].lowercaseChar() == 'q'
                            if (!isAfterQ) {
                                result[idx - 1] = if (result[idx - 1].isUpperCase()) 'Ư' else 'ư'
                                transformed = true
                                break
                            }
                        }
                        result[idx] = if (vUpper) 'Ă' else 'ă'
                        transformed = true
                        break
                    } else if (vLower == 'o' || vLower == 'ô') {
                        if (idx >= 1) {
                            val prevLower = result[idx - 1].lowercaseChar()
                            val isAfterQ = idx >= 2 && result[idx - 2].lowercaseChar() == 'q'
                            if (!isAfterQ && (prevLower == 'u' || prevLower == 'ư')) {
                                result[idx - 1] = if (result[idx - 1].isUpperCase()) 'Ư' else 'ư'
                            }
                        }
                        result[idx] = if (vUpper) 'Ơ' else 'ơ'
                        transformed = true
                        break
                    } else if (vLower == 'u') {
                        if (idx >= 1 && (result[idx - 1].lowercaseChar() == 'o' || result[idx - 1].lowercaseChar() == 'ơ')) {
                            continue
                        }
                        val isSingleUAfterQ = idx >= 1 && result[idx - 1].lowercaseChar() == 'q'
                        if (isSingleUAfterQ) continue
                        if (idx >= 1 && result[idx - 1].lowercaseChar() == 'u') {
                            result[idx - 1] = if (result[idx - 1].isUpperCase()) 'Ư' else 'ư'
                            transformed = true
                            break
                        }
                        result[idx] = if (vUpper) 'Ư' else 'ư'
                        transformed = true
                        break
                    }
                }
                if (transformed) {
                    i += 1
                    continue
                } else {
                    result.add(ch)
                    i += 1
                    continue
                }
            }

            // 7. Phím dấu thanh Telex (s, f, r, x, j) và phím xóa dấu (z)
            val hasVowels = !result.any { it.lowercaseChar() == 'w' } && result.any { isVietnameseVowel(it) }
            if (hasVowels && lower in "sfrxjz") {
                if (lower == 'z' && tone != Tone.NONE) {
                    tone = Tone.NONE
                    i += 1
                    continue
                }
                val newTone = when (lower) {
                    's' -> Tone.ACUTE
                    'f' -> Tone.GRAVE
                    'r' -> Tone.HOOK
                    'x' -> Tone.TILDE
                    'j' -> Tone.DOT
                    else -> null
                }
                if (newTone != null) {
                    if (toneEscapeActive) {
                        result.add(ch)
                        i += 1
                        continue
                    }
                    if (tone == newTone) {
                        // Nhấn lặp lại cùng phím dấu để hủy dấu và xuất chữ cái thường (vd: canhf + f -> canhf)
                        tone = Tone.NONE
                        toneEscapeActive = true
                        result.add(ch)
                    } else {
                        tone = newTone
                    }
                    i += 1
                    continue
                }
            }

            // 8. Tốc gõ phụ âm cuối (-g -> -ng, -h -> -nh, -k -> -c)
            if (relaxedCoda && !toneEscapeActive && hasVowels &&
                result.lastOrNull()?.let { isVietnameseVowel(it) } == true &&
                ((i + 1) until chars.size).all { chars[it].lowercaseChar() in "sfrxjzwaeod" }
            ) {
                when (lower) {
                    'g' -> {
                        result.addAll((if (ch.isUpperCase()) "NG" else "ng").toList())
                        i += 1
                        continue
                    }
                    'h' -> {
                        result.addAll((if (ch.isUpperCase()) "NH" else "nh").toList())
                        i += 1
                        continue
                    }
                    'k' -> {
                        result.add(if (ch.isUpperCase()) 'C' else 'c')
                        i += 1
                        continue
                    }
                }
            }

            result.add(ch)
            i += 1
        }

        // Đồng bộ cụm nguyên âm đôi 'ưo' -> 'ươ' khi có phụ âm/nguyên âm theo sau (vd: truwongr -> trưởng, dduwocj -> được)
        if (!hornCancelled && result.size >= 3) {
            for (idx in 0 until result.size - 2) {
                if (result[idx].lowercaseChar() == 'ư' && result[idx + 1].lowercaseChar() == 'o') {
                    result[idx + 1] = if (result[idx + 1].isUpperCase()) 'Ơ' else 'ơ'
                }
            }
        }

        if (tone != Tone.NONE) {
            applyTone(result, tone, modernOrthography)
        }
        return result.joinToString("")
    }

    // ==================== QUY TẮC ĐẶT DẤU CHUẨN TIẾNG VIỆT ====================
    private fun applyTone(chars: MutableList<Char>, tone: Tone, modern: Boolean) {
        if (tone == Tone.NONE) return
        val vowelIndices = chars.indices.filter { isVietnameseVowel(chars[it]) }
        if (vowelIndices.isEmpty()) return

        // Bổ sung phụ âm cuối -k (teen-code cho -c) vào tập coda để đặt dấu đúng trên âm tiết đóng
        val validCodaChars = setOf('c', 'm', 'n', 'p', 't', 'g', 'h', 'k')
        val targetIndex: Int = when (vowelIndices.size) {
            1 -> vowelIndices[0]
            2 -> {
                val firstV = chars[vowelIndices[0]].lowercaseChar()
                val secondV = chars[vowelIndices[1]].lowercaseChar()
                val isFallingOffglide = secondV == 'u' ||
                    (secondV == 'o' && firstV != 'u') ||
                    (secondV == 'i' && firstV != 'u') ||
                    (secondV == 'y' && firstV != 'u')
                val trailingIsCoda = vowelIndices[1] < chars.lastIndex &&
                    chars[vowelIndices[1] + 1].lowercaseChar() in validCodaChars
                val hasCoda = trailingIsCoda && !isFallingOffglide

                if (vowelIndices[0] > 0 && chars[vowelIndices[0] - 1].lowercaseChar() == 'q' && firstV == 'u') {
                    vowelIndices[1]
                } else if (vowelIndices[0] > 0 && chars[vowelIndices[0] - 1].lowercaseChar() == 'g' && firstV == 'i') {
                    vowelIndices[1]
                } else if (hasCoda) {
                    vowelIndices[1]
                } else {
                    val pair = "$firstV$secondV"
                    when {
                        // Từ Nam Bộ / chuẩn tiếng Việt có vần "ia" (dzìa, tía, mía), "ua", "ưa" đặt dấu ở nguyên âm đầu;
                        // riêng "oa", "oe", "uy", "uê" đặt dấu theo chuẩn mới/cũ
                        pair == "oa" || pair == "oe" || pair == "uy" || pair == "uê" ->
                            if (modern) vowelIndices[1] else vowelIndices[0]
                        pair == "iê" || pair == "yê" || pair == "uô" || pair == "ươ" || pair == "ưo" || pair == "uơ" ->
                            vowelIndices[1]
                        else -> vowelIndices[0]
                    }
                }
            }
            else -> {
                val lastVIdx = vowelIndices.last()
                val hasCoda = lastVIdx < chars.lastIndex && chars[lastVIdx + 1].lowercaseChar() in validCodaChars
                if (hasCoda) {
                    lastVIdx
                } else {
                    val lastLower = chars[lastVIdx].lowercaseChar()
                    if (lastLower == 'i' || lastLower == 'y' || lastLower == 'u') {
                        vowelIndices[vowelIndices.size - 2]
                    } else {
                        val modIdx = vowelIndices.firstOrNull { chars[it].lowercaseChar() in "âêôơưă" }
                        modIdx ?: vowelIndices[vowelIndices.size - 2]
                    }
                }
            }
        }
        chars[targetIndex] = addToneToVowel(chars[targetIndex], tone)
    }

    private fun rawKeysFor(text: String): String {
        val sb = StringBuilder()
        var toneKey: Char? = null
        for (ch in text) {
            val isUpper = ch.isUpperCase()
            val lower = ch.lowercaseChar()
            if (lower == 'đ') {
                sb.append(if (isUpper) "DD" else "dd")
                continue
            }
            val base = REVERSE_BASE_VOWEL_MAP[lower]
            val toneIdx = TONE_INDEX_MAP[lower] ?: 0
            if (base != null) {
                val rawBase = when (base) {
                    'ă' -> "aw"
                    'â' -> "aa"
                    'ê' -> "ee"
                    'ô' -> "oo"
                    'ơ' -> "ow"
                    'ư' -> "uw"
                    else -> base.toString()
                }
                val cased = if (isUpper) rawBase.replaceFirstChar { it.uppercaseChar() } else rawBase
                sb.append(cased)
                if (toneIdx > 0) {
                    toneKey = when (toneIdx) {
                        1 -> 's'
                        2 -> 'f'
                        3 -> 'r'
                        4 -> 'x'
                        5 -> 'j'
                        else -> null
                    }
                }
            } else {
                sb.append(ch)
            }
        }
        if (toneKey != null) sb.append(toneKey)
        return sb.toString()
    }

    companion object {
        private val ENGLISH_FJZ_PROTECTED_WORDS = setOf(
            "fee", "fees", "feel", "feed", "feet", "fast", "first", "file", "files", "find", "fine", "fire", "firm",
            "five", "flat", "flow", "focus", "folder", "follow", "font", "food", "foot", "force", "form", "format",
            "found", "four", "frame", "free", "fresh", "friend", "from", "front", "full", "func", "function", "fund",
            "future", "zero", "zeros", "zone", "zones", "zoom", "zip", "zest", "zebra", "just", "join", "json", "java",
            "job", "jobs", "jump", "june", "july", "judge"
        )

        private val ENGLISH_W_PROTECTED_WORDS = setOf(
            "water", "want", "wants", "wait", "walk", "wall", "warm", "warn", "wash", "watch", "wave", "way", "ways",
            "wear", "weather", "web", "week", "weeks", "weight", "welcome", "well", "went", "were", "west", "what",
            "when", "where", "which", "while", "white", "who", "whole", "whom", "whose", "why", "wide", "wife", "wild",
            "will", "win", "wind", "window", "windows", "wine", "wing", "winter", "wire", "wise", "wish", "with",
            "within", "without", "woman", "women", "wonder", "wood", "word", "words", "work", "works", "world",
            "worry", "worse", "worst", "worth", "would", "write", "writer", "wrong"
        )

        private val TONE_VOWEL_TABLE: Map<Char, List<Char>> = mapOf(
            // [none, acute, grave, hook, tilde, dot]
            'a' to listOf('a', 'á', 'à', 'ả', 'ã', 'ạ'),
            'ă' to listOf('ă', 'ắ', 'ằ', 'ẳ', 'ẵ', 'ặ'),
            'â' to listOf('â', 'ấ', 'ầ', 'ẩ', 'ẫ', 'ậ'),
            'e' to listOf('e', 'é', 'è', 'ẻ', 'ẽ', 'ẹ'),
            'ê' to listOf('ê', 'ế', 'ề', 'ể', 'ễ', 'ệ'),
            'i' to listOf('i', 'í', 'ì', 'ỉ', 'ĩ', 'ị'),
            'o' to listOf('o', 'ó', 'ò', 'ỏ', 'õ', 'ọ'),
            'ô' to listOf('ô', 'ố', 'ồ', 'ổ', 'ỗ', 'ộ'),
            'ơ' to listOf('ơ', 'ớ', 'ờ', 'ở', 'ỡ', 'ợ'),
            'u' to listOf('u', 'ú', 'ù', 'ủ', 'ũ', 'ụ'),
            'ư' to listOf('ư', 'ứ', 'ừ', 'ử', 'ữ', 'ự'),
            'y' to listOf('y', 'ý', 'ỳ', 'ỷ', 'ỹ', 'ỵ'),
        )

        private val REVERSE_BASE_VOWEL_MAP: Map<Char, Char> = buildMap {
            for ((base, tones) in TONE_VOWEL_TABLE) {
                for (t in tones) put(t, base)
            }
        }

        private val TONE_INDEX_MAP: Map<Char, Int> = buildMap {
            for ((_, tones) in TONE_VOWEL_TABLE) {
                tones.forEachIndexed { idx, t -> put(t, idx) }
            }
        }

        fun isVietnameseVowel(ch: Char): Boolean = REVERSE_BASE_VOWEL_MAP.containsKey(ch.lowercaseChar())

        fun addToneToVowel(ch: Char, tone: Tone): Char {
            val isUpper = ch.isUpperCase()
            val lower = ch.lowercaseChar()
            val base = REVERSE_BASE_VOWEL_MAP[lower] ?: return ch
            val row = TONE_VOWEL_TABLE[base] ?: return ch
            val accented = row.getOrElse(tone.index) { ch }
            return if (isUpper) accented.uppercaseChar() else accented
        }
    }

    var secondarySymbol: String? = null

            invalidate()
        }

    private val symbolPaint = Paint(Paint.ANTI_ALIAS_FLAG).apply {
        textAlign = Paint.Align.RIGHT
        typeface = Typeface.create("sans-serif", Typeface.NORMAL)
    }

    override fun onDraw(canvas: Canvas) {
        // 1. Let AppCompatButton draw the centered single-line primary letter
        super.onDraw(canvas)

        // 2. Draw the secondary symbol badge in the top-right corner of the key (Gboard style)
        val sec = secondarySymbol
        if (!sec.isNullOrEmpty()) {
            val density = resources.displayMetrics.density
            val scaledDensity = resources.displayMetrics.scaledDensity
            symbolPaint.textSize = 10.5f * scaledDensity
            symbolPaint.color = context.getColor(R.color.key_hint)

            val x = width - (4.5f * density)
            val fm = symbolPaint.fontMetrics
            val y = (3.5f * density) - fm.ascent
            canvas.drawText(sec, x, y, symbolPaint)
        }
    }
}

    private fun onShiftPressed() {
        val now = System.currentTimeMillis()
        shiftState = when (shiftState) {
            ShiftState.LOWER -> ShiftState.SHIFTED
            ShiftState.SHIFTED -> if (now - lastShiftClickTime < 400L) ShiftState.CAPS_LOCK else ShiftState.LOWER
            ShiftState.CAPS_LOCK -> ShiftState.LOWER
        }
        lastShiftClickTime = now
        refreshLetterKeyLabels()
    }

    private fun updateAutoCapitalization() {
        if (!prefs.autoCapitalization || shiftState == ShiftState.CAPS_LOCK) return
        val ic = currentInputConnection ?: return
        val before = ic.getTextBeforeCursor(32, 0)?.toString().orEmpty()
        val trimmed = before.trimEnd()
        val shouldCap = trimmed.isEmpty() || trimmed.endsWith(".") || trimmed.endsWith("!") || trimmed.endsWith("?") || before.endsWith("\n")
        shiftState = if (shouldCap) ShiftState.SHIFTED else ShiftState.LOWER
        refreshLetterKeyLabels()
    }

    private fun onSecondarySymbol(symbol: String) {
        val ic = currentInputConnection ?: return
        // Nếu ký hiệu phụ là chữ cái tiếng Việt (vd: phím D có ký hiệu phụ 'đ'/'Đ' chuẩn Gboard Tiếng Việt),
        // tự động khớp chữ HOA/thường theo trạng thái Shift và đưa vào bộ gõ.
        if (symbol.length == 1 && symbol[0].isLetter()) {
            val ch = if (shiftState != ShiftState.LOWER) symbol.uppercase()[0] else symbol.lowercase()[0]
            onChar(ch)
            if (shiftState == ShiftState.SHIFTED) {
                shiftState = ShiftState.LOWER
                refreshLetterKeyLabels()
            }
            return
        }
        commitRaw(symbol)
    }

    private fun onSpacePressed() {
        val ic = currentInputConnection ?: return
        val now = System.currentTimeMillis()
        // Gboard Double-space period option
        if (prefs.doubleSpacePeriod && now - lastSpaceClickTime < 350L && !vnEngine.isComposing) {
            val before = ic.getTextBeforeCursor(2, 0)?.toString().orEmpty()
            if (before.length == 2 && before[1] == ' ' && before[0].isLetterOrDigit()) {
                ic.beginBatchEdit()
                ic.deleteSurroundingText(1, 0)
                ic.commitText(". ", 1)
                ic.endBatchEdit()
                lastSpaceClickTime = 0L
                updateAutoCapitalization()
                updateSuggestions("")
                return
            }
        }
        lastSpaceClickTime = now
        onChar(' ')
    }

    private fun onPunctuation(c: Char) {
        onChar(c)
        if (prefs.autoSpaceAfterPunctuation && (c == ',' || c == '.' || c == '!' || c == '?')) {
            currentInputConnection?.commitText(" ", 1)
        }
        updateAutoCapitalization()
    }

    private fun onChar(c: Char) {
        val ic = currentInputConnection ?: return
        if (mode != Mode.LETTERS) {
            commitRaw(c.toString())
            return
        }
        if (isMacroTrigger(c)) {
            val finishedWord = vnEngine.composingText
            vnEngine.commit(ic)
            if (finishedWord.isNotEmpty()) {
                recordCommittedWord(finishedWord)
            }
            if (prefs.macroEnabled && macroEngine.tryExpand(ic, c)) {
                syncContextFromEditor()
                updateAutoCapitalization()
                updateSuggestions("")
                return
            }
            ic.commitText(c.toString(), 1)
            updateAutoCapitalization()
            updateSuggestions("")
            return
        }

        val handled = vnEngine.onChar(c, ic)
        if (!handled) {
            vnEngine.commit(ic)
            ic.commitText(c.toString(), 1)
        }
        updateSuggestions(vnEngine.composingText)
    }

    private fun commitRaw(text: String) {
        val ic = currentInputConnection ?: return
        vnEngine.commit(ic)
        ic.commitText(text, 1)
        updateAutoCapitalization()
        updateSuggestions("")
    }

    private fun onBackspace() {
        val ic = currentInputConnection ?: return
        if (mode == Mode.LETTERS && vnEngine.onBackspace(ic)) {
            updateSuggestions(vnEngine.composingText)
            return
        }
        ic.deleteSurroundingText(1, 0)
        updateAutoCapitalization()
        updateSuggestions("")
    }

    private fun deleteWordBeforeCursor() {
        val ic = currentInputConnection ?: return
        if (vnEngine.isComposing) {
            vnEngine.reset(ic)
            updateSuggestions("")
            return
        }
        val before = ic.getTextBeforeCursor(64, 0)?.toString().orEmpty()
        if (before.isEmpty()) return
        val trailingSpaces = before.takeLastWhile { it.isWhitespace() }.length
        val wordLen = before.dropLast(trailingSpaces).takeLastWhile { !it.isWhitespace() }.length
        val totalDelete = (trailingSpaces + wordLen).coerceAtLeast(1)
        ic.deleteSurroundingText(totalDelete, 0)
        updateAutoCapitalization()
        updateSuggestions("")
    }

    private fun onEnter() {
        val ic = currentInputConnection ?: return
        vnEngine.commit(ic)
        ic.sendKeyEvent(KeyEvent(KeyEvent.ACTION_DOWN, KeyEvent.KEYCODE_ENTER))
        ic.sendKeyEvent(KeyEvent(KeyEvent.ACTION_UP, KeyEvent.KEYCODE_ENTER))
        updateAutoCapitalization()
        updateSuggestions("")
    }

    private fun onStripDiacritics() {
        val ic = currentInputConnection ?: return
        vnEngine.removeDiacritics(ic)
        updateSuggestions(vnEngine.composingText)
    }

    private fun onPasteClipboard() {
        if (!prefs.enableClipboardHistory) return
        val cm = getSystemService(Context.CLIPBOARD_SERVICE) as? ClipboardManager ?: return
        val clip = cm.primaryClip
        if (clip != null && clip.itemCount > 0) {
            val text = clip.getItemAt(0).coerceToText(this)?.toString().orEmpty()
            if (text.isNotEmpty()) commitRaw(text)
        }
    }

    private fun openSettingsSection(section: String?) {

    private fun switchKeyboard() {
        val imm = getSystemService(INPUT_METHOD_SERVICE) as InputMethodManager
        val token: IBinder? = window.window?.attributes?.token
        if (token != null && imm.shouldOfferSwitchingToNextInputMethod(token)) {
            imm.switchToNextInputMethod(token, false)
        } else {
            imm.showInputMethodPicker()
        }
    }

    private fun performKeyFeedback(view: View, isLongPress: Boolean = false) {
        if (prefs.hapticOnKeypress) {
            val flag = if (isLongPress) HapticFeedbackConstants.LONG_PRESS else HapticFeedbackConstants.KEYBOARD_TAP
            view.performHapticFeedback(flag)
        }
        if (prefs.soundOnKeypress) {
            val am = getSystemService(Context.AUDIO_SERVICE) as? AudioManager
            val vol = (prefs.soundVolume / 100f).coerceIn(0f, 1f)
            am?.playSoundEffect(AudioManager.FX_KEY_CLICK, vol)
        }
    }

    /**
     * Chỉ phím chữ mới có symbol phụ ở góc trên bên phải (vẽ bằng GboardKeyButton,
     * chữ cái chính luôn nằm chính giữa phím, không bao giờ bị tụt hay bị cắt).
     */
    private fun applyLetterKeyLabel(btn: GboardKeyButton, primary: String, secondary: String?) {
        btn.text = primary
        btn.secondarySymbol = secondary
    }

    /**
     * Bảng ký hiệu phụ chuẩn Gboard Tiếng Việt dành riêng cho 26 phím chữ cái:
     * - Khi đã bật Hàng phím số (showNumberRow = true), hàng Q..P hiển thị bộ ký hiệu Gboard: % \ | = [ ] < > { }
     * - Khi tắt Hàng phím số (showNumberRow = false), hàng Q..P hiển thị số: 1 2 3 4 5 6 7 8 9 0
     * - Hàng A..L: @ # đ _ & - + ( )
     * - Hàng Z..M: * " ' : ; ! ?
     */
    private fun secondarySymbolForLetter(letterKey: String): String? = when (letterKey.lowercase()) {
        // Hàng chữ trên (QWERTYUIOP)
        "q" -> if (prefs.showNumberRow) "%" else "1"
        "w" -> if (prefs.showNumberRow) "\\" else "2"
        "e" -> if (prefs.showNumberRow) "|" else "3"
        "r" -> if (prefs.showNumberRow) "=" else "4"
        "t" -> if (prefs.showNumberRow) "[" else "5"
        "y" -> if (prefs.showNumberRow) "]" else "6"
        "u" -> if (prefs.showNumberRow) "<" else "7"
        "i" -> if (prefs.showNumberRow) ">" else "8"
        "o" -> if (prefs.showNumberRow) "{" else "9"
        "p" -> if (prefs.showNumberRow) "}" else "0"
        // Hàng chữ giữa (ASDFGHJKL) - chuẩn Gboard Tiếng Việt (D -> đ, F -> _)
        "a" -> "@"
        "s" -> "#"
        "d" -> if (shiftState != ShiftState.LOWER) "Đ" else "đ"
        "f" -> "_"
        "g" -> "&"
        "h" -> "-"
        "j" -> "+"
        "k" -> "("
        "l" -> ")"
        // Hàng chữ dưới (ZXCVBNM)
        "z" -> "*"
        "x" -> "\""
        "c" -> "'"
        "v" -> ":"
        "b" -> ";"
        "n" -> "!"
        "m" -> "?"
        else -> null
    }

    /**
     * Gboard 3-slot suggestion strip with Trigram Next-Word & Context-Aware Word Suggestions.
     */
    private fun updateSuggestions(prefix: String) {
        val bar = suggestionBar ?: return
        bar.removeAllViews()
        if (!prefs.showSuggestionStrip || mode != Mode.LETTERS) return

        syncContextFromEditor()

        val macroPreview = if (prefs.macroEnabled && prefix.isNotEmpty()) {
            macroEngine.lookupPreview(prefix)
        } else null

        val suggestions = when {
            prefix.isNotEmpty() -> suggestionEngine.suggest(
                prefix = prefix,
                prevWord1 = prevCommittedWord1,
                prevWord2 = prevCommittedWord2,
                limit = 3,
                includeEmoji = prefs.showEmojiSuggestions,
                macroPreview = macroPreview,
            )
            prefs.nextWordSuggestions -> suggestionEngine.suggestNextWord(
                prevWord1 = prevCommittedWord1,
                prevWord2 = prevCommittedWord2,
                limit = 3,
            )
            else -> emptyList()
        }

        suggestions.forEachIndexed { index, word ->
            if (index > 0) {
                val divider = View(this).apply {
                    layoutParams = LinearLayout.LayoutParams(2, 42)
                    setBackgroundColor(getColor(R.color.strip_divider))
                }
                bar.addView(divider)
            }
            val isPrimaryCenter = (index == 1 && prefix.isNotEmpty()) || (macroPreview != null && word == macroPreview)
            val tv = TextView(this).apply {
                text = word
                gravity = Gravity.CENTER
                maxLines = 1
                layoutParams = LinearLayout.LayoutParams(0, LinearLayout.LayoutParams.MATCH_PARENT, 1f)
                setTextColor(
                    if (isPrimaryCenter) getColor(R.color.suggestion_primary)
                    else getColor(R.color.key_text)
                )
                setTypeface(typeface, if (isPrimaryCenter) Typeface.BOLD else Typeface.NORMAL)
                textSize = 15f
                setOnClickListener {
                    performKeyFeedback(this)
                    acceptSuggestion(word)
                }
            }
            bar.addView(tv)
        }
    }

    private fun acceptSuggestion(word: String) {
        val ic = currentInputConnection ?: return
        val hadComposing = vnEngine.isComposing
        vnEngine.reset(ic)
        if (!hadComposing) {
            val before = ic.getTextBeforeCursor(32, 0)?.toString().orEmpty()
            val prefix = before.takeLastWhile { it.isLetter() }
            if (prefix.isNotEmpty()) ic.deleteSurroundingText(prefix.length, 0)
        }
        ic.commitText("$word ", 1)
        recordCommittedWord(word)
        updateAutoCapitalization()
        updateSuggestions("")
    }

    private fun recordCommittedWord(word: String) {
        val clean = word.trim()
        if (clean.isEmpty()) return
        val tokens = clean.split(Regex("\\s+")).filter { it.isNotEmpty() }
        for (token in tokens) {
            suggestionEngine.learn(token, prevWord1 = prevCommittedWord1, prevWord2 = prevCommittedWord2)
            prevCommittedWord2 = prevCommittedWord1
            prevCommittedWord1 = token
        }
    }

    private fun syncContextFromEditor() {
        val ic = currentInputConnection ?: return
        val before = ic.getTextBeforeCursor(64, 0)?.toString().orEmpty()
        val committedPart = if (vnEngine.isComposing && before.endsWith(vnEngine.composingText)) {
            before.dropLast(vnEngine.composingText.length)
        } else {
            before
        }
        val tokens = committedPart
            .trim()
            .split(Regex("[\\s.,;:!?()\\[\\]\"']+"))
            .filter { it.isNotEmpty() }
        prevCommittedWord1 = tokens.getOrNull(tokens.size - 1).orEmpty()
        prevCommittedWord2 = tokens.getOrNull(tokens.size - 2).orEmpty()
    }

    private fun isMacroTrigger(c: Char): Boolean = c.isWhitespace() || c in ".,;:!?\n"

package com.vnchflex.vietkeyboard.macro

import android.view.inputmethod.InputConnection

/**
 * Macro replacement engine with vnchKey smart case adaptation
 * (e.g. "hn" -> "Hà Nội", "HN" -> "HÀ NỘI", "dc" -> "được", "Dc" -> "Được", "DC" -> "ĐƯỢC")
 * and technical delimiter suppression (e.g. `.vn`, `user@hn`, `file_dc.txt`).
 */
class MacroEngine(initialMacros: List<Macro> = emptyList()) {
    @Volatile
    private var macros: List<Macro> = initialMacros

    fun update(newMacros: List<Macro>) {
        macros = newMacros
    }

    fun tryExpand(ic: InputConnection, trigger: Char): Boolean {
        if (isTechnicalDelimiter(trigger) || trigger in "([{<") return false

        val before = ic.getTextBeforeCursor(MAX_LOOKBACK, 0)?.toString() ?: return false
        val token = before.takeLastWhile { !it.isWhitespace() && !isTechnicalDelimiter(it) }
        if (token.isEmpty()) return false

        val charBeforeTokenIdx = before.length - token.length - 1
        if (charBeforeTokenIdx >= 0 && isTechnicalDelimiter(before[charBeforeTokenIdx])) {
            return false
        }

        val macro = findMacro(token) ?: return false
        val expanded = adaptCase(token, resolveVariables(macro.expansion))

        ic.beginBatchEdit()
        try {
            val deleted = ic.deleteSurroundingText(token.length, 0)
            if (!deleted) return false
            ic.commitText(expanded + trigger, 1)
        } finally {
            ic.endBatchEdit()
        }
        return true
    }

    fun findMacro(token: String): Macro? = macros.firstOrNull { m ->
        m.enabled && (if (m.caseSensitive) m.shortcut == token else m.shortcut.equals(token, ignoreCase = true))
    }

    fun lookupPreview(token: String): String? {
        if (token.isEmpty()) return null
        val macro = findMacro(token) ?: return null
        return adaptCase(token, resolveVariables(macro.expansion))
    }

    private fun adaptCase(inputToken: String, expansion: String): String {
        if (expansion.isEmpty()) return expansion
        if (inputToken.length >= 2 && inputToken == inputToken.uppercase() && inputToken != inputToken.lowercase()) {
            return expansion.uppercase()
        }
        if (inputToken.first().isUpperCase()) {
            return expansion.replaceFirstChar { it.uppercaseChar() }
        }
        return expansion
    }

    private fun resolveVariables(text: String): String {
        val now = java.time.ZonedDateTime.now()
        return text
            .replace("{date}", now.toLocalDate().toString())
            .replace("{time}", now.toLocalTime().withNano(0).toString())
    }

    private fun isTechnicalDelimiter(c: Char): Boolean = c in "/@_-#\\=$~`0123456789"

    companion object {
        private const val MAX_LOOKBACK = 64
    }
}

class MacroStore(context: Context) {

    fun load(): List<Macro> {
        val raw = prefs.getString(KEY_MACROS, null) ?: return defaultMacros()
        return runCatching { parse(raw) }.getOrElse { defaultMacros() }
    }

    fun save(macros: List<Macro>) {
        prefs.edit().putString(KEY_MACROS, serialize(macros)).apply()
    }

    fun resetToDefaults(): List<Macro> {
        val defaults = defaultMacros()
        save(defaults)
        return defaults
    }

    private fun parse(raw: String): List<Macro> {
        val arr = JSONArray(raw)
        return List(arr.length()) { i ->
            val o = arr.getJSONObject(i)
            Macro(
                shortcut = o.getString("shortcut"),
                expansion = o.getString("expansion"),
                caseSensitive = o.optBoolean("caseSensitive", false),
                enabled = o.optBoolean("enabled", true),
            )
        }
    }

        val arr = JSONArray()

            arr.put(JSONObject().apply {
                put("shortcut", m.shortcut)

    private fun navigateTo(screen: Screen) {
        currentScreen = screen
        container.removeAllViews()
        btnBack.visibility = if (screen == Screen.MAIN) View.GONE else View.VISIBLE

        when (screen) {
            Screen.MAIN -> renderMainScreen()
            Screen.LANGUAGES_VNCHKEY -> renderLanguagesVnchKeyScreen()

            Screen.THEME -> renderThemeScreen()
            Screen.TEXT_CORRECTION -> renderTextCorrectionScreen()
            Screen.DICTIONARY -> renderDictionaryScreen()
            Screen.PERSONAL_DICTIONARY -> renderPersonalDictionaryScreen()
            Screen.MACRO_EDITOR -> renderMacroEditorScreen()
            Screen.GLIDE_TYPING -> renderGlideTypingScreen()
            Screen.VOICE_CLIPBOARD -> renderVoiceClipboardScreen()
            Screen.ADVANCED -> renderAdvancedScreen()
            Screen.ABOUT -> renderAboutScreen()
        }
    }

    private fun showPersonalWordDialog(existing: PersonalWord?) {
        val layout = LinearLayout(this).apply {
            orientation = LinearLayout.VERTICAL
            setPadding(48, 24, 48, 8)
        }
        val etWord = EditText(this).apply {
            hint = "Từ hoặc cụm từ (vd: Việt Nam)"
            setText(existing?.word.orEmpty())
        }
        val etShortcut = EditText(this).apply {
            hint = "Lối tắt không bắt buộc (vd: vn)"
            setText(existing?.shortcut.orEmpty())
        }
        layout.addView(etWord)
        layout.addView(etShortcut)

        val builder = AlertDialog.Builder(this)
            .setTitle(if (existing == null) "Thêm vào Từ điển cá nhân" else "Sửa từ cá nhân")
            .setView(layout)
            .setPositiveButton("Lưu") { _, _ ->
                val word = etWord.text.toString().trim()
                val sc = etShortcut.text.toString().trim()
                if (word.isNotEmpty()) {
                    if (existing != null && !existing.word.equals(word, ignoreCase = true)) {
                        dictStore.removePersonalWord(existing.word)
                    }
                    dictStore.addPersonalWord(word, sc)
                    navigateTo(Screen.PERSONAL_DICTIONARY)
                }
            }
            .setNegativeButton("Hủy", null)

        if (existing != null) {
            builder.setNeutralButton("Xóa") { _, _ ->
                dictStore.removePersonalWord(existing.word)
                navigateTo(Screen.PERSONAL_DICTIONARY)
            }
        }
        builder.show()
    }

    private fun showMacroDialog(existing: Macro?) {
        val layout = LinearLayout(this).apply {
            orientation = LinearLayout.VERTICAL
            setPadding(48, 24, 48, 8)
        }
        val etShortcut = EditText(this).apply {
            hint = "Từ viết tắt (vd: hn, cty, addr)"
            setText(existing?.shortcut.orEmpty())
        }
        val etExpansion = EditText(this).apply {
            hint = "Cụm từ thay thế (vd: Hà Nội)"
            setText(existing?.expansion.orEmpty())
        }
        layout.addView(etShortcut)
        layout.addView(etExpansion)

        val builder = AlertDialog.Builder(this)
            .setTitle(if (existing == null) "Thêm phím tắt mới" else "Chỉnh sửa phím tắt")
            .setView(layout)
            .setPositiveButton("Lưu") { _, _ ->
                val sc = etShortcut.text.toString().trim().lowercase()
                val exp = etExpansion.text.toString().trim()
                if (sc.isNotEmpty() && exp.isNotEmpty()) {
                    val list = macroStore.load().toMutableList()
                    if (existing != null) {
                        list.removeAll { it.shortcut.equals(existing.shortcut, ignoreCase = true) }
                    }
                    list.removeAll { it.shortcut.equals(sc, ignoreCase = true) }
                    list.add(0, Macro(sc, exp))
                    macroStore.save(list)
                    navigateTo(Screen.MACRO_EDITOR)
                }
            }
            .setNegativeButton("Hủy", null)

        if (existing != null) {
            builder.setNeutralButton("Xóa") { _, _ ->
                val list = macroStore.load().filterNot { it.shortcut.equals(existing.shortcut, ignoreCase = true) }
                macroStore.save(list)
                navigateTo(Screen.MACRO_EDITOR)
            }
        }
        builder.show()
    }

package com.vnchflex.vietkeyboard.suggestion

import android.content.Context
import org.json.JSONArray
import org.json.JSONObject

data class PersonalWord(
    val word: String,
    val shortcut: String = "",
    val locale: String = "vi_VN",
)

/**
 * Gboard-style Personal Dictionary & Learned N-gram (Unigram / Bigram / Trigram) store.
 */
class PersonalDictionaryStore(context: Context) {
    private val prefs = context.getSharedPreferences(PREFS_NAME, Context.MODE_PRIVATE)

    fun loadPersonalWords(): List<PersonalWord> {
        val raw = prefs.getString(KEY_PERSONAL_WORDS, null) ?: return defaultPersonalWords()
        return runCatching {
            val arr = JSONArray(raw)
            List(arr.length()) { i ->
                val o = arr.getJSONObject(i)
                PersonalWord(
                    word = o.getString("word"),
                    shortcut = o.optString("shortcut", ""),
                    locale = o.optString("locale", "vi_VN"),
                )
            }
        }.getOrElse { defaultPersonalWords() }
    }

    fun savePersonalWords(words: List<PersonalWord>) {
        val arr = JSONArray()
        words.forEach { w ->
            arr.put(JSONObject().apply {
                put("word", w.word)
                put("shortcut", w.shortcut)
                put("locale", w.locale)
            })
        }
        prefs.edit().putString(KEY_PERSONAL_WORDS, arr.toString()).apply()
    }

    fun addPersonalWord(word: String, shortcut: String = "", locale: String = "vi_VN") {
        val cleanWord = word.trim()
        if (cleanWord.isEmpty()) return
        val current = loadPersonalWords().toMutableList()
        current.removeAll { it.word.equals(cleanWord, ignoreCase = true) && it.locale == locale }
        current.add(0, PersonalWord(cleanWord, shortcut.trim(), locale))
        savePersonalWords(current)
    }

    fun removePersonalWord(word: String) {
        val current = loadPersonalWords().filterNot { it.word.equals(word, ignoreCase = true) }
        savePersonalWords(current)
    }

    fun loadLearnedWords(): Set<String> {
        return prefs.getStringSet(KEY_LEARNED_WORDS, emptySet())?.toSet() ?: emptySet()
    }

    fun addLearnedWord(word: String) {
        val w = word.trim().lowercase()
        if (w.length < 2) return
        val current = loadLearnedWords().toMutableSet()
        current.add(w)
        prefs.edit().putStringSet(KEY_LEARNED_WORDS, current).apply()
    }

    fun loadLearnedBigrams(): Map<String, Map<String, Int>> {
        val raw = prefs.getString(KEY_LEARNED_BIGRAMS, null) ?: return emptyMap()
        return parseNgramJson(raw)
    }

    fun saveLearnedBigrams(bigrams: Map<String, Map<String, Int>>) {
        prefs.edit().putString(KEY_LEARNED_BIGRAMS, serializeNgramJson(bigrams)).apply()
    }

    fun loadLearnedTrigrams(): Map<String, Map<String, Int>> {
        val raw = prefs.getString(KEY_LEARNED_TRIGRAMS, null) ?: return emptyMap()
        return parseNgramJson(raw)
    }

    fun saveLearnedTrigrams(trigrams: Map<String, Map<String, Int>>) {
        prefs.edit().putString(KEY_LEARNED_TRIGRAMS, serializeNgramJson(trigrams)).apply()
    }

    /** Gboard: Delete learned words & n-gram history (Xóa các từ và ngữ cảnh đã học) */
    fun clearLearnedWords() {
        prefs.edit()
            .remove(KEY_LEARNED_WORDS)
            .remove(KEY_LEARNED_BIGRAMS)
            .remove(KEY_LEARNED_TRIGRAMS)
            .apply()
    }

    private fun parseNgramJson(raw: String): Map<String, Map<String, Int>> = runCatching {
        val root = JSONObject(raw)
        val out = mutableMapOf<String, Map<String, Int>>()
        val keys = root.keys()
        while (keys.hasNext()) {
            val k = keys.next()
            val childObj = root.getJSONObject(k)
            val childMap = mutableMapOf<String, Int>()
            val cKeys = childObj.keys()
            while (cKeys.hasNext()) {
                val ck = cKeys.next()
                childMap[ck] = childObj.optInt(ck, 1)
            }
            if (childMap.isNotEmpty()) out[k] = childMap
        }
        out
    }.getOrDefault(emptyMap())

    private fun serializeNgramJson(data: Map<String, Map<String, Int>>): String {
        val root = JSONObject()
        data.entries.take(MAX_STORED_CONTEXTS).forEach { (ctx, followers) ->
            val child = JSONObject()
            followers.entries
                .sortedByDescending { it.value }
                .take(MAX_FOLLOWERS_PER_CONTEXT)
                .forEach { (w, count) -> child.put(w, count) }
            root.put(ctx, child)
        }
        return root.toString()
    }

    private fun defaultPersonalWords(): List<PersonalWord> = listOf(
        PersonalWord("Việt Nam", "vn", "vi_VN"),
        PersonalWord("vnchFlex", "vf", "vi_VN"),
        PersonalWord("Sen Việt", "sv", "vi_VN"),
    )

    companion object {
        private const val PREFS_NAME = "gboard_personal_dictionary"
        private const val KEY_PERSONAL_WORDS = "personal_words"
        private const val KEY_LEARNED_WORDS = "learned_words"
        private const val KEY_LEARNED_BIGRAMS = "learned_bigrams_v1"
        private const val KEY_LEARNED_TRIGRAMS = "learned_trigrams_v1"
        private const val MAX_STORED_CONTEXTS = 400
        private const val MAX_FOLLOWERS_PER_CONTEXT = 8
    }
}

        dictStore?.loadLearnedTrigrams()?.forEach { (ctx, map) ->
            userTrigrams[ctx] = map.toMutableMap()
        }
    }

    /**
     * Gợi ý từ đang gõ (Word Suggestions):
     * - Khớp tiền tố có dấu và tiền tố không dấu (`"viet"` -> `"việt"`, `"dzia"` -> `"dzìa"`, `"dzach"` -> `"dzách"`).
     * - Ưu tiên các từ phù hợp với ngữ cảnh Trigram `(prevWord2, prevWord1)` và Bigram `(prevWord1)`.
     */
    fun suggest(
        prefix: String,
        prevWord1: String = "",
        prevWord2: String = "",
        limit: Int = 3,
        includeEmoji: Boolean = true,
        macroPreview: String? = null,
    ): List<String> {
        val q = prefix.trim()
        if (q.isEmpty()) return emptyList()
        val lower = q.lowercase()
        val strippedQuery = DiacriticUtils.strip(lower)
        val isUpperFirst = q.first().isUpperCase()

        val results = mutableListOf<String>()
        // Slot 0 (Gboard left slot): exact composing text
        results.add(q)

        // Slot 1 priority: Macro preview or Personal Dictionary shortcut
        if (!macroPreview.isNullOrEmpty() && !results.contains(macroPreview)) {
            results.add(macroPreview)
        }

        val personalWords = dictStore?.loadPersonalWords().orEmpty()
        personalWords.forEach { pw ->
            val pwLower = pw.word.lowercase()
            val pwStripped = DiacriticUtils.strip(pwLower)
            if (pw.shortcut.equals(lower, ignoreCase = true) ||
                pwLower.startsWith(lower) ||
                pwStripped.startsWith(strippedQuery)
            ) {
                if (!results.contains(pw.word)) results.add(pw.word)
            }
        }

        if (includeEmoji) {
            (emojiMap[lower] ?: emojiMap[strippedQuery])?.let { emoji ->
                if (!results.contains(emoji)) results.add(emoji)
            }
        }

        // Contextual Trigram & Bigram candidate boosts for prefix completion
        val contextualFollowers = getContextualWeights(prevWord2, prevWord1)

        val allWords = LinkedHashSet<String>().apply {
            addAll(userUnigramCounts.keys)
            addAll(coreUnigramWeights.keys)
        }

        val scoredCandidates = allWords
            .filter { candidate ->
                if (candidate.equals(lower, ignoreCase = true)) return@filter false
                val candStripped = DiacriticUtils.strip(candidate)
                candidate.startsWith(lower) || candStripped.startsWith(strippedQuery)
            }
            .map { candidate ->
                val exactPrefixBoost = if (candidate.startsWith(lower)) 250 else 100
                val contextBoost = (contextualFollowers[candidate] ?: 0) * 120
                val userBoost = (userUnigramCounts[candidate] ?: 0) * 15
                val baseWeight = coreUnigramWeights[candidate] ?: 50
                val lengthPenalty = (candidate.length - lower.length).coerceAtLeast(0) * 4
                val totalScore = exactPrefixBoost + contextBoost + userBoost + baseWeight - lengthPenalty
                candidate to totalScore
            }
            .sortedByDescending { it.second }

        scoredCandidates.forEach { (candidate, _) ->
            val cased = if (isUpperFirst) candidate.replaceFirstChar { it.uppercaseChar() } else candidate
            if (!results.contains(cased)) results.add(cased)
        }

        return results.take(limit)
    }

    /**
     * Gợi ý từ tiếp theo theo mô hình Trigram `(prevWord2, prevWord1) -> nextWord`
     * với Katz Backoff về Bigram `(prevWord1) -> nextWord` và Unigram.
     */
    fun suggestNextWord(
        prevWord1: String,
        prevWord2: String = "",
        limit: Int = 3,
    ): List<String> {
        val p1 = prevWord1.trim().lowercase()
        val p2 = prevWord2.trim().lowercase()
        if (p1.isEmpty()) return listOf("Tôi", "Xin", "Mình").take(limit)

        val candidates = LinkedHashSet<String>()

        // 1. Trigram lookup: (p2, p1) -> nextWord
        if (p2.isNotEmpty()) {
            val trigramKey = "$p2 $p1"
            userTrigrams[trigramKey]?.entries
                ?.sortedByDescending { it.value }
                ?.forEach { candidates.add(it.key) }
            bundledTrigrams[trigramKey]?.forEach { candidates.add(it) }
        }

        // 2. Katz Backoff -> Bigram lookup: (p1) -> nextWord
        if (candidates.size < limit) {
            userBigrams[p1]?.entries
                ?.sortedByDescending { it.value }
                ?.forEach { candidates.add(it.key) }
            bundledBigrams[p1]?.forEach { candidates.add(it) }
        }

        // 3. Backoff -> High-frequency Vietnamese connectors / unigrams
        if (candidates.size < limit) {
            listOf("là", "có", "và", "được", "không", "nha").forEach {
                if (!it.equals(p1, ignoreCase = true)) candidates.add(it)
            }
        }

        return candidates.take(limit)
    }

    /**
     * Học từ đơn (Unigram) + cặp từ (Bigram) + bộ 3 từ (Trigram) khi người dùng nhập xong từ.
     */
    fun learn(word: String, prevWord1: String = "", prevWord2: String = "") {
        val w = word.trim().lowercase()
        if (w.length < 2) return

        // 1. Learn Unigram
        userUnigramCounts[w] = (userUnigramCounts[w] ?: 0) + 1
        dictStore?.addLearnedWord(w)

        // 2. Learn Bigram (prevWord1 -> w)
        val p1 = prevWord1.trim().lowercase()
        if (p1.isNotEmpty()) {
            val bMap = userBigrams.getOrPut(p1) { mutableMapOf() }
            bMap[w] = (bMap[w] ?: 0) + 1
            dictStore?.saveLearnedBigrams(userBigrams)

            // 3. Learn Trigram (prevWord2 + " " + prevWord1 -> w)
            val p2 = prevWord2.trim().lowercase()
            if (p2.isNotEmpty()) {
                val tKey = "$p2 $p1"
                val tMap = userTrigrams.getOrPut(tKey) { mutableMapOf() }
                tMap[w] = (tMap[w] ?: 0) + 1
                dictStore?.saveLearnedTrigrams(userTrigrams)
            }
        }
    }

    fun clearLearnedWords() {
        userUnigramCounts.clear()
        userBigrams.clear()
        userTrigrams.clear()
        dictStore?.clearLearnedWords()
    }

    private fun getContextualWeights(prevWord2: String, prevWord1: String): Map<String, Int> {
        val weights = mutableMapOf<String, Int>()
        val p1 = prevWord1.trim().lowercase()
        val p2 = prevWord2.trim().lowercase()
        if (p1.isEmpty()) return weights

        if (p2.isNotEmpty()) {
            val tKey = "$p2 $p1"
            bundledTrigrams[tKey]?.forEachIndexed { idx, w ->
                weights[w] = (weights[w] ?: 0) + (10 - idx).coerceAtLeast(3)
            }
            userTrigrams[tKey]?.forEach { (w, count) ->
                weights[w] = (weights[w] ?: 0) + count * 6
            }
        }

        bundledBigrams[p1]?.forEachIndexed { idx, w ->
            weights[w] = (weights[w] ?: 0) + (5 - idx).coerceAtLeast(1)
        }
        userBigrams[p1]?.forEach { (w, count) ->
            weights[w] = (weights[w] ?: 0) + count * 3
        }
        return weights
    }
}
